# Using Zapier

The Zapier integration lets you connect Ledgerly to other apps without code. It is available on the Growth plan and above.

Ledgerly triggers include: invoice sent, invoice paid, invoice overdue, new customer, and new expense. Ledgerly actions include: create customer, create draft invoice, and create expense.

Zaps run with the permissions of the Ledgerly user who connected Zapier. If that user is removed from the workspace, the Zaps stop working until another user reconnects.
