# Billing expenses to customers

When you mark an expense as billable and choose a customer, Ledgerly holds it as an unbilled expense. The next time you create an invoice for that customer, Ledgerly shows a banner listing their unbilled expenses. Select the expenses you want to add, and each becomes a line item.

You can add a markup percentage to billable expenses in Settings > Expense defaults. The markup applies only to new invoices.

An expense can be billed only once. If you void the invoice it was billed on, the expense returns to the unbilled list.
